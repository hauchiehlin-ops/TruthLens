DOCX Editing History as AI Evidence

Original editable documents can preserve clues that a pasted PDF or copied text cannot show.

What DOCX and ODT Can Reveal

Depending on the editor and file history, DOCX or ODT files may contain creation and modification times, total editing duration, save counts, revision identifiers, and writing-session markers. A long essay with only a few minutes of editing time deserves a different review than a file with a gradual drafting record.

These signals are not proof by themselves. Files can be copied, converted, cleaned, or edited under unusual conditions. The value is that source evidence can challenge or support the language signal.

How OmniTrace Uses It

OmniTrace keeps source evidence separate from AI probability. It can say that text looks AI-like while also reporting that provenance is unavailable, weak, or needs review. This prevents the common mistake of turning missing metadata into a direct authorship claim.

For confidential documents, local analysis is especially important. The original source file may contain sensitive internal metadata, so it should not be uploaded casually to an opaque scoring service.

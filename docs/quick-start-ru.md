## 5️⃣ Просмотрите отчет

### Верхняя секция：**Карточка сводки вердикта**
```
╔════════════════════════════════════╗
║  Вердикт：Вероятно создано ИИ    ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║  Вероятность ИИ：72%              ║
║  Уверенность：Высокая ✓          ║
╚════════════════════════════════════╝
```

**📌 Значение**：
- **Вердикт**：Общее суждение（человек / вероятно человек / смешанное / вероятно ИИ / ИИ）
- **Вероятность**：Степень уверенности в создании ИИ（0～100%）
- **Уверенность**：Согласны ли все двигатели обнаружения

---

### Средняя секция：**Карточки метрик 3 столбцов**
```
┌──────────────┬──────────────┬──────────────┐
│  Доля ИИ    │ Время анализа │  Уверенность │
│  ────────    │ ────────      │  ────────   │
│  8/45 (18%)  │  2,3 сек      │  92%        │
└──────────────┴──────────────┴──────────────┘
```

**📌 Значение**：
- **Доля ИИ**：Сколько предложений отмечено как ИИ（8 из 45）
- **Время анализа**：Время сканирования
- **Уверенность**：Надежность общего результата

---

### Нижняя секция：**Список подозрительных предложений**
```
【Предложение #1】（стр. 3）Риск：Высокий 🔴 | Уверенность 85%
  "Синергетический сдвиг парадигмы позволяет..."
  Причина：Высокое сходство, необычная сложность словарного запаса, ритмический паттерн

【Предложение #2】（стр. 5）Риск：Средний 🟡 | Уверенность 72%
  "Алгоритмы машинного обучения инициировали революцию..."
  Причина：Статистическое отклонение, низкое разнообразие словарного запаса
```

**📌 Как читать**：
- **Номер страницы**：Положение в документе
- **Цвет риска**：Красный（высокий риск）, желтый（средний риск）, синий（низкий риск）
- **Процент ИИ**：Вероятность того, что это ИИ（0～100%）
- **Причина**：Почему модель отметила это предложение

## 6️⃣ Интерпретируйте результаты（Для учителей）

### Сценарий A：Общая вероятность ИИ > 80%
```
⚠️ Сильные доказательства использования ИИ
→ Действие：Внимательно изучите подозрительные предложения
→ Далее：Обсудите со студентом, разрешена ли ИИ по политике
```

### Сценарий B：Вероятность ИИ 50～80%
```
🤔 Смешанные сигналы; некоторые абзацы подозрительны
→ Действие：Сосредоточьтесь на предложениях, отмеченных красным
→ Далее：Проверьте, соответствуют ли они типичному стилю студента
```

### Сценарий C：Вероятность ИИ < 30%
```
✅ Похоже на подлинную работу студента
→ Действие：Рассмотрите одобрение или проверьте несколько предложений
→ Примечание：Человеческие тексты также могут иметь ложные срабатывания
```

## 🆘 Распространенные проблемы и решения

### Проблема：「Ошибка загрузки модели」
```
❌ Ошибка：Не удается загрузить модель RoBERTa
✅ Решение：
  1. Проверьте подключение к интернету
  2. Отключите VPN/прокси
  3. Подождите 5 минут и повторите попытку
  4. Очистите кэш браузера（Ctrl+Shift+Del）
```

### Проблема：「Анализ очень медленный」
```
❌ Ожидание более 30 секунд
✅ Решение：
  1. Первый запуск медленный（загрузка моделей в ОЗУ）
  2. Последующие запуски занимают 2～5 секунд
  3. Закройте другие вкладки браузера
  4. Перезагрузите браузер, если остается медленным
```

### Проблема：「Браузер говорит 'недостаточно памяти'」
```
❌ Ошибка：Не удается выделить память
✅ Решение：
  1. Требуется минимум 2 ГБ свободной ОЗУ
  2. Закройте другие приложения
  3. Обновите страницу（Cmd/Ctrl + R）
  4. Попробуйте на настольном компьютере
```

## 2️⃣ AI 탐지 모델 다운로드（처음 한 번만）

앱을 열면 설정 패널이 표시됩니다：

```
┌─ 모델 설치 ─────────────────┐
│ RoBERTa 탐지기 (125.8 MB)   │
│ └─ [다운로드] ✓ 설치됨      │
│                              │
│ 다국어 탐지기 (135 MB)     │
│ └─ [다운로드] ✓ 설치됨      │
│                              │
│ 통계 엔진 (82 MB)          │
│ └─ [다운로드] 선택사항      │
│                              │
│ 대적 방어 (135 MB)         │
│ └─ [다운로드] 선택사항      │
│                              │
│ LLM 보고서 생성 (1.7 GB)  │
│ └─ [다운로드] 선택사항      │
└──────────────────────────────┘
```

**⏱️ 초기 설정**：약 3 분（인터넷 속도에 따라）

**다운로드 내용？**
- 핵심 탐지 모델：약 350 MB（필수）
- 더 나은 보고서 작성용 LLM：약 1.7 GB（선택사항）

**다운로드 후**：모든 분석이 오프라인에서 실행됩니다！✅

## 3️⃣ 파일 업로드 또는 텍스트 붙여넣기

### 방법 1：텍스트 붙여넣기
```
1. 「텍스트 붙여넣기」를 클릭
2. Ctrl+V（또는 Cmd+V）로 텍스트 붙여넣기
3. 권장：최소 100 자
```

### 방법 2：파일 업로드
```
지원 형식：
• .txt（텍스트 파일）
• .docx（Word 파일）
• .pdf（PDF 파일, OCR 지원）
```

### 방법 3：카메라 사용（모바일）
```
1. 카메라 아이콘을 탭
2. 손으로 쓴 과제 사진 촬영
3. OCR 이 자동으로 이미지 → 텍스트로 변환
```

## 5️⃣ 보고서 확인

### 상단 섹션：**판정 요약 카드**
```
╔════════════════════════════════════╗
║  판정：AI 가능성 있음             ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║  AI 확률：72%                      ║
║  신뢰도：높음 ✓                   ║
╚════════════════════════════════════╝
```

**📌 의미**：
- **판정**：전체 판단（인간 / 아마도 인간 / 혼합 / AI 가능성 / AI）
- **확률**：AI 생성 신뢰도（0～100%）
- **신뢰도**：모든 탐지 엔진이 일치하는지 여부

---

### 중앙 섹션：**3 열 지표 카드**
```
┌──────────────┬──────────────┬──────────────┐
│  AI 비율     │ 분석 시간    │  신뢰도      │
│  ────────    │ ────────     │  ────────   │
│  8/45 (18%)  │  2.3 초      │  92%        │
└──────────────┴──────────────┴──────────────┘
```

**📌 의미**：
- **AI 비율**：AI 로 표시된 문장 수（45 개 중 8 개）
- **분석 시간**：스캔 소요 시간
- **신뢰도**：전체 결과의 신뢰성

---

### 하단 섹션：**의심스러운 문장 목록**
```
【문장 #1】（3 페이지）위험：높음 🔴 | 신뢰도 85%
  "시너지 패러다임 시프트가 가능하게 한다..."
  판정 근거：높은 유사도, 어휘 복잡도 이상, 규칙적인 리듬

【문장 #2】（5 페이지）위험：중간 🟡 | 신뢰도 72%
  "머신러닝 알고리즘은 혁명을 일으켰다..."
  판정 근거：통계적 특성 이탈, 낮은 어휘 다양성
```

**📌 읽는 방법**：
- **페이지 번호**：문서 내 위치
- **위험 색상**：빨강（높은 위험）, 노랑（중간 위험）, 파랑（낮은 위험）
- **AI 백분율**：AI일 가능성 0～100%
- **판정 근거**：모델이 해당 문장을 표시한 이유

## 6️⃣ 결과 해석（교사용）

### 시나리오 A：전체 AI 확률 > 80%
```
⚠️ AI 사용의 강한 증거
→ 조치：의심스러운 문장을 자세히 살펴보기
→ 다음：과제 정책이 AI 사용을 허용하는지 학생과 논의
```

### 시나리오 B：AI 확률 50～80%
```
🤔 혼합 신호; 일부 단락이 의심스러움
→ 조치：빨강으로 표시된 문장에 집중
→ 다음：해당 학생의 일반적인 저술 스타일과 일치하는지 확인
```

### 시나리오 C：AI 확률 < 30%
```
✅ 진정한 학생 작업처럼 보임
→ 조치：합격 고려 또는 몇 문장 표본 검사
→ 주의：인간 텍스트도 오탐지가 발생할 수 있습니다
```

## 🆘 일반적인 문제 및 해결 방법

### 문제：「모델 다운로드 실패」
```
❌ 오류：RoBERTa 모델을 다운로드할 수 없습니다
✅ 해결 방법：
  1. 인터넷 연결 확인
  2. VPN/프록시 비활성화
  3. 5 분 후 다시 시도
  4. 브라우저 캐시 지우기（Ctrl+Shift+Del）
```

### 문제：「분석이 매우 느림」
```
❌ 30 초 이상 대기
✅ 해결 방법：
  1. 초기 실행이 느림（모델을 RAM 에 로드）
  2. 이후 실행은 2～5 초
  3. 다른 브라우저 탭 닫기
  4. 여전히 느리면 브라우저 재시작
```

### 문제：「브라우저가 '메모리 부족'이라고 함」
```
❌ 오류：메모리를 할당할 수 없습니다
✅ 해결 방법：
  1. 2GB 이상의 여유 RAM 필요
  2. 다른 응용 프로그램 닫기
  3. 페이지 새로 고침（Cmd/Ctrl + R）
  4. 데스크톱 컴퓨터에서 시도
```

### 문제：「보고서에 '신뢰도가 낮다'고 표시됨」
```
❌ 경고：분석 신뢰도가 60% 미만
✅ 설명：
  - 일부 탐지 모델을 로드할 수 없음
  - 결과 신뢰성 낮을 수 있음; 재실행 고려
  - 「모델 설치」패널 확인
```

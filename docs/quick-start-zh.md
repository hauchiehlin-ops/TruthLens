# TruthLens — 快速開始指南（通用中文）

**目標**：在 5 分鐘内完成您的第一份文檔分析

---

## 1️⃣ 打開應用

### 方式 A：網頁版本（推薦）
```
瀏覽器：https://truthlens.vercel.app
設備：桌機、平板或手機
```
✅ 無須安裝  
✅ 下載模型後可離線使用  
✅ 100% 隱私保障

### 方式 B：本地開發
```bash
git clone https://github.com/hauchiehlin-ops/TruthLens.git
cd TruthLens
flutter pub get
flutter run -d web-server
# 在 http://localhost:8765 打開
```

## 3️⃣ 上傳文件或貼上文本

### 方法 1：貼上文本
```
1. 點擊「貼上文本」
2. 按 Ctrl+V（或 Cmd+V）貼上
3. 建議：至少 100 字
```

### 方法 2：上傳文件
```
支持的格式：
• .txt（文本文件）
• .docx（Word 文件）
• .pdf（PDF 文件，含 OCR）
```

### 方法 3：使用相機（移動設備）
```
1. 點擊相機圖標
2. 拍攝您的手寫作業
3. OCR 自動將圖像轉換 → 文本
```

## 5️⃣ 查看報告

### 上部分：**判定摘要卡片**
```
╔════════════════════════════════════╗
║  判定：可能由 AI 生成             ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║  AI 概率：72%                      ║
║  信心度：高 ✓                     ║
╚════════════════════════════════════╝
```

**📌 含義**：
- **判定**：總體判斷（人類 / 可能人類 / 混合 / 可能 AI / AI）
- **概率**：AI 生成的信心度（0～100%）
- **信心度**：所有檢測引擎是否一致

---

### 中部分：**3 列指標卡片**
```
┌──────────────┬──────────────┬──────────────┐
│  AI 比例     │ 分析時間     │  信心度      │
│  ────────    │ ────────     │  ────────   │
│  8/45 (18%)  │  2.3 秒      │  92%        │
└──────────────┴──────────────┴──────────────┘
```

**📌 含義**：
- **AI 比例**：多少句子被標記為 AI（45 中的 8 句）
- **分析時間**：掃描耗時
- **信心度**：整體結果的可靠性

---

### 下部分：**可疑句子列表**
```
【句子 #1】（第 3 頁）風險：高 🔴 | 信心度 85%
  "協同範式轉變使..."
  原因：相似度高、詞彙複雜度異常、韻律規律

【句子 #2】（第 5 頁）風險：中 🟡 | 信心度 72%
  "機器學習演算法引發了革命..."
  原因：統計特徵偏離、詞彙多樣性低
```

**📌 讀法**：
- **頁碼**：文檔中的位置
- **風險色彩**：紅色（高風險）、黃色（中風險）、藍色（低風險）
- **AI 百分比**：是 AI 的概率（0～100%）
- **原因**：模型為何標記該句子

## 6️⃣ 解釋結果（教師指南）

### 情景 A：整體 AI 概率 > 80%
```
⚠️ 明確證據表明使用了 AI
→ 行動：仔細檢查可疑句子
→ 下一步：與學生討論政策是否允許 AI
```

### 情景 B：AI 概率 50～80%
```
🤔 混合信號；某些段落可疑
→ 行動：重點關注紅色標記的句子
→ 下一步：檢查是否符合該學生的典型寫作風格
```

### 情景 C：AI 概率 < 30%
```
✅ 看起來是真實的學生作業
→ 行動：考慮通過或抽查幾句
→ 注意：人類文本也可能產生假陽性
```

## 🆘 常見問題和解決方案

### 問題：「模型下載失敗」
```
❌ 錯誤：無法下載 RoBERTa 模型
✅解決方案：
  1. 檢查網絡連接
  2. 禁用 VPN/代理
  3. 等待 5 分鐘後重試
  4. 清空瀏覽器快取（Ctrl+Shift+Del）
```

### 問題：「分析非常慢」
```
❌ 等待超過 30 秒
✅ 解決方案：
  1. 首次運行較慢（將模型加載到 RAM）
  2. 後續運行需要 2～5 秒
  3. 關閉其他瀏覽器標籤
  4. 如果仍然很慢，請重啟瀏覽器
```

### 問題：「瀏覽器提示'內存不足'」
```
❌ 錯誤：無法分配內存
✅ 解決方案：
  1. 需要至少 2 GB 可用 RAM
  2. 關閉其他應用程序
  3. 刷新頁面（Cmd/Ctrl + R）
  4. 在桌機上嘗試
```

## 1️⃣ 打開應用程式

### 選項 A：Web 版本（推薦）
```
瀏覽器：https://truthlens.vercel.app
裝置：桌機、平板或手機
```
✅ 無需安裝  
✅ 下載模型後可離線使用  
✅ 100% 隱私保護

```bash
git clone https://github.com/hauchiehlin-ops/TruthLens.git
cd TruthLens
flutter pub get
flutter run -d web-server
# 打開 http://localhost:8765
```

## 3️⃣ 上傳或貼上文件

### 方式 1：貼上文本
```
1. 點擊「貼上文本」
2. Ctrl+V（或 Cmd+V）貼上您的文本
3. 建議至少 100 個字符
```

### 方式 2：上傳文件
```
支援的格式：
• .txt（文本檔案）
• .docx（Word 文件）
• .pdf（PDF 檔案，包含 OCR）
```

### 方式 3：使用相機（行動裝置）
```
1. 點擊相機圖標
2. 拍攝手寫作業照片
3. OCR 自動轉換圖片 → 文本
```

## 4️⃣ 開始分析

點擊藍色的 **「分析」** 按鈕

```

（通常 2-10 秒，取決於文件長度）
```

## 5️⃣ 查看報告

### 頂部區段：**判定摘要卡**
```
╔════════════════════════════════════╗
║  判定：可能為 AI                   ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║  AI 概率：72%                      ║
║  可信度：高度可信 ✓               ║
╚════════════════════════════════════╝
```

**📌 含義**：
- **判定**：整體判斷（人類 / 可能人類 / 混合 / 可能 AI / AI）
- **概率**：0-100% 的 AI 生成確信度
- **可信度**：所有檢測引擎是否一致

---

### 中間區段：**三列指標卡**
```
┌──────────────┬──────────────┬──────────────┐
│  AI 比例     │ 分析耗時     │  可信度      │
│  ────────    │ ────────     │  ────────   │
│  8/45 (18%)  │  2.3 秒      │  92%        │
└──────────────┴──────────────┴──────────────┘
```

**📌 含義**：
- **AI 比例**：多少句子被標記為 AI（45 句中 8 句）
- **分析耗時**：掃描用時
- **可信度**：整體結果的可靠性

---

### 底部區段：**可疑句子清單**
```
【句子 #1】（第 3 頁）風險：高危 🔴 | 信心度 85%
  「整合典範轉移能夠啟用...」
  判定依據：相似度高、詞彙複雜度異常、節奏規律

【句子 #2】（第 5 頁）風險：中等 🟡 | 信心度 72%
  「機器學習演算法已經徹底改變...」
  判定依據：統計特徵偏差、詞彙多樣性低
```

**📌 如何解讀**：
- **頁數**：文件中的位置
- **風險色彩**：紅色（高危）、黃色（中等）、藍色（低危）
- **AI 百分比**：0-100% 的 AI 可能性
- **判定依據**：為何模型標記該句子

## 6️⃣ 解讀結果（教師用）

### 情況 A：整體 AI 概率 > 80%
```
⚠️ 強力 AI 使用跡象
→ 行動：深入檢查可疑句子
→ 後續：與學生討論作業政策是否允許使用 AI
```

### 情況 B：AI 概率 50-80%
```
🤔 混合信號；某些段落可疑
→ 行動：聚焦紅色標記句子
→ 後續：檢查是否符合該學生的典型寫作風格
```

### 情況 C：AI 概率 < 30%
```
✅ 看起來是真正的學生作業
→ 行動：考慮通過，或抽查幾個句子
→ 注意：即使人類文本也可能觸發假陽性
```

## 🆘 常見問題與解決方案

### 問題：「模型下載失敗」
```
❌ 錯誤：無法下載 RoBERTa 模型
✅ 解決方法：
  1. 檢查網路連線
  2. 停用 VPN/代理
  3. 5 分鐘後重試
  4. 清除瀏覽器快取（Ctrl+Shift+Del）
```

### 問題：「分析非常慢」
```
❌ 等待 30 秒以上
✅ 解決方法：
  1. 首次運行速度較慢（將模型載入 RAM）
  2. 後續運行 2-5 秒
  3. 關閉其他瀏覽器標籤頁
  4. 若仍然緩慢，重新啟動瀏覽器
```

### 問題：「瀏覽器說『記憶體不足』」
```
❌ 錯誤：RAM 用盡
✅ 解決方法：
  1. 需要 2GB+ 的可用 RAM
  2. 關閉其他應用程式
  3. 重新整理頁面（Cmd/Ctrl + R）
  4. 嘗試在桌機而非行動裝置上使用
```

### 問題：「報告顯示『可信度低』」
```
❌ 警告：分析可信度低於 60%
✅ 說明：
  - 某些檢測模型無法加載
  - 結果可靠性較低；考慮重新運行
  - 檢查「模型安裝」面板
```

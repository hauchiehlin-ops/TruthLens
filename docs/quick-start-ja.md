# TruthLens — クイックスタートガイド（日本語）

**目標**：5 分で最初のドキュメント分析を完了する

---

## 1️⃣ アプリを開く

### オプション A：Web バージョン（推奨）
```
ブラウザ：https://truthlens.vercel.app
デバイス：デスクトップ、タブレット、モバイル
```
✅ インストール不要  
✅ モデルダウンロード後はオフラインで使用可能  
✅ 100% プライバシー保護

### オプション B：ローカル開発
```bash
git clone https://github.com/hauchiehlin-ops/TruthLens.git
cd TruthLens
flutter pub get
flutter run -d web-server
# http://localhost:8765 で開く
```

## 3️⃣ ファイルをアップロードまたは貼り付ける

### 方法 1：テキストを貼り付ける
```
1. 「テキストを貼り付ける」をクリック
2. Ctrl+V（または Cmd+V）でテキストを貼り付け
3. 推奨：最低 100 文字
```

### 方法 2：ファイルをアップロード
```
対応形式：
• .txt（テキストファイル）
• .docx（Word ファイル）
• .pdf（PDF ファイル、OCR 対応）
```

### 方法 3：カメラを使用（モバイル）
```
1. カメラアイコンをタップ
2. 手書きの課題の写真を撮影
3. OCR が自動的に画像 → テキストに変換
```

## 5️⃣ レポートを確認

### トップセクション：**判定要約カード**
```
╔════════════════════════════════════╗
║  判定：AI の可能性あり             ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║  AI 確率：72%                      ║
║  信頼度：高い ✓                   ║
╚════════════════════════════════════╝
```

**📌 意味**：
- **判定**：総合判断（人間 / おそらく人間 / 混合 / AI の可能性 / AI）
- **確率**：AI 生成の確信度（0～100%）
- **信頼度**：すべての検出エンジンが一致しているかどうか

---

### 中央セクション：**3 列の指標カード**
```
┌──────────────┬──────────────┬──────────────┐
│  AI 比率     │ 分析時間     │  信頼度      │
│  ────────    │ ────────     │  ────────   │
│  8/45 (18%)  │  2.3 秒      │  92%        │
└──────────────┴──────────────┴──────────────┘
```

**📌 意味**：
- **AI 比率**：何文が AI とフラグされたか（45 文中 8 文）
- **分析時間**：スキャン所要時間
- **信頼度**：全体的な結果の信頼性

---

### ボトムセクション：**疑わしい文の一覧**
```
【文 #1】（第 3 ページ）リスク：高 🔴 | 信頼度 85%
  "シナジーパラダイムシフトが可能にする..."
  判定根拠：相似度高、語彙複雑度異常、リズム規則

【文 #2】（第 5 ページ）リスク：中 🟡 | 信頼度 72%
  "機械学習アルゴリズムが革命をもたらした..."
  判定根拠：統計的特性の逸脱、語彙多様性が低い
```

**📌 読み方**：
- **ページ番号**：ドキュメント内の位置
- **リスク色**：赤（高リスク）、黄（中リスク）、青（低リスク）
- **AI パーセンテージ**：AI である可能性 0～100%
- **判定根拠**：モデルがその文をフラグした理由

## 6️⃣ 結果を解釈する（教師向け）

### シナリオ A：全体的な AI 確率 > 80%
```
⚠️ AI 使用の強い証拠
→ アクション：疑わしい文を詳しく調べる
→ 次：課題のポリシーで AI の使用が許可されているかどうかを学生と相談
```

### シナリオ B：AI 確率 50～80%
```
🤔 混合信号；一部の段落が疑わしい
→ アクション：赤でフラグされた文に注目
→ 次：その学生の典型的な執筆スタイルと一致するかどうかを確認
```

### シナリオ C：AI 確率 < 30%
```
✅ 本当の学生の作業のように見える
→ アクション：合格を検討するか、数文をスポットチェック
→ 注意：人間のテキストでも誤検出が発生する可能性がある
```

## 🆘 よくある問題と解決方法

### 問題：「モデルダウンロード失敗」
```
❌ エラー：RoBERTa モデルをダウンロードできません
✅ 解決方法：
  1. インターネット接続を確認
  2. VPN/プロキシを無効化
  3. 5 分待ってから再試行
  4. ブラウザキャッシュをクリア（Ctrl+Shift+Del）
```

### 問題：「分析が非常に遅い」
```
❌ 30 秒以上待機
✅ 解決方法：
  1. 初回実行は遅い（モデルを RAM に読み込む）
  2. 以降の実行は 2～5 秒
  3. 他のブラウザタブを閉じる
  4. それでも遅い場合はブラウザを再起動
```

### 問題：「ブラウザが『メモリ不足』と言う」
```
❌ エラー：RAM を割り当てできません
✅ 解決方法：
  1. 2GB 以上の空き RAM が必要
  2. 他のアプリケーションを閉じる
  3. ページを更新（Cmd/Ctrl + R）
  4. デスクトップコンピュータで試す
```

### 問題：「レポートに『信頼度が低い』と表示される」
```
❌ 警告：分析信頼度が 60% 未満
✅ 説明：
  - 一部の検出モデルが読み込めなかった
  - 結果の信頼性が低い可能性；再実行を検討
  - 「モデルインストール」パネルを確認
```

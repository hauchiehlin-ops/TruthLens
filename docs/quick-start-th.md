# TruthLens — คู่มือเริ่มต้นอย่างรวดเร็ว（ไทย）

**เป้าหมาย**：ทำให้การวิเคราะห์เอกสารครั้งแรกของคุณเสร็จสิ้นใน 5 นาที

---

## 1️⃣ เปิดแอปพลิเคชัน

### ตัวเลือก A：เวอร์ชัน Web（แนะนำ）
```
เบราว์เซอร์：https://truthlens.vercel.app
อุปกรณ์：เดสก์ทอป แท็บเล็ต หรือโทรศัพท์มือถือ
```
✅ ไม่ต้องติดตั้ง  
✅ สามารถใช้งานแบบออฟไลน์หลังจากดาวน์โหลดโมเดล  
✅ ความเป็นส่วนตัว 100% รับประกัน

### ตัวเลือก B：การพัฒนาในเครื่อง
```bash
git clone https://github.com/hauchiehlin-ops/TruthLens.git
cd TruthLens
flutter pub get
flutter run -d web-server
# เปิดที่ http://localhost:8765
```

## 2️⃣ ดาวน์โหลดโมเดลตรวจสอบ AI（เพียงครั้งเดียว）

เมื่อคุณเปิดแอพ จะมีแผงการกำหนดค่าปรากฏขึ้น：

```
┌─ การติดตั้งโมเดล ──────────────┐
│ ตัวตรวจสอบ RoBERTa (125.8 MB) │
│ └─ [ดาวน์โหลด] ✓ ติดตั้งแล้ว  │
│                                 │
│ ตัวตรวจสอบหลายภาษา (135 MB)  │
│ └─ [ดาวน์โหลด] ✓ ติดตั้งแล้ว  │
│                                 │
│ เอ็นจิน สถิติ (82 MB)          │
│ └─ [ดาวน์โหลด] ตัวเลือก      │
│                                 │
│ การป้องกัน Adversarial (135 MB)│
│ └─ [ดาวน์โหลด] ตัวเลือก      │
│                                 │
│ การสร้างรายงาน LLM (1.7 GB)  │
│ └─ [ดาวน์โหลด] ตัวเลือก      │
└─────────────────────────────────┘
```

**⏱️ การตั้งค่าเบื้องต้น**：ประมาณ 3 นาที（ขึ้นอยู่กับความเร็วอินเทอร์เน็ต）

**มีอะไรดาวน์โหลด？**
- โมเดลตรวจสอบหลัก：~350 MB（จำเป็น）
- LLM สำหรับการสร้างรายงานที่ดีขึ้น：~1.7 GB（ตัวเลือก）

**หลังจากดาวน์โหลด**：การวิเคราะห์ทั้งหมดทำงานแบบออฟไลน์ทั้งหมด！✅

## 3️⃣ อัปโหลดไฟล์หรือวางข้อความ

### วิธี 1：วางข้อความ
```
1. คลิก 「วางข้อความ」
2. กดปุ่ม Ctrl+V（หรือ Cmd+V）เพื่อวาง
3. แนะนำ：อย่างน้อย 100 อักขระ
```

### วิธี 2：อัปโหลดไฟล์
```
รูปแบบที่รองรับ：
• .txt（ไฟล์ข้อความ）
• .docx（ไฟล์ Word）
• .pdf（ไฟล์ PDF พร้อม OCR）
```

### วิธี 3：ใช้กล้อง（อุปกรณ์เคลื่อนที่）
```
1. แตะไอคอนกล้อง
2. ถ่ายภาพการเขียนด้วยมือของคุณ
3. OCR จะแปลงรูปภาพเป็นข้อความโดยอัตโนมัติ
```

## 5️⃣ ตรวจสอบรายงาน

### ส่วนบนสุด：**การ์ดสรุปคำตัดสิน**
```
╔════════════════════════════════════╗
║  คำตัดสิน：อาจสร้างโดย AI        ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║  ความน่าจะเป็นของ AI：72%          ║
║  ความมั่นใจ：สูง ✓               ║
╚════════════════════════════════════╝
```

**📌 ความหมาย**：
- **คำตัดสิน**：การตัดสินใจโดยรวม（มนุษย์ / อาจเป็นมนุษย์ / ผสม / อาจเป็น AI / AI）
- **ความน่าจะเป็น**：ระดับความมั่นใจในการสร้างโดย AI（0～100%）
- **ความมั่นใจ**：ว่าเอ็นจินตรวจสอบทั้งหมดเห็นด้วยหรือไม่

---

### ส่วนกลาง：**การ์ดเมตริก 3 คอลัมน์**
```
┌──────────────┬──────────────┬──────────────┐
│  อัตราส่วน AI│ เวลาวิเคราะห์│ ความมั่นใจ   │
│  ────────    │ ────────     │  ────────   │
│  8/45 (18%)  │  2.3 วินาที  │  92%        │
└──────────────┴──────────────┴──────────────┘
```

**📌 ความหมาย**：
- **อัตราส่วน AI**：มีกี่ประโยคที่ทำเครื่องหมายเป็น AI（8 จาก 45）
- **เวลาวิเคราะห์**：เวลาการสแกน
- **ความมั่นใจ**：ความน่าเชื่อถือของผลลัพธ์โดยรวม

---

### ส่วนล่าง：**รายการประโยคที่น่าสงสัย**
```
【ประโยค #1】（หน้า 3）ความเสี่ยง：สูง 🔴 | ความมั่นใจ 85%
  "การเปลี่ยนแปลงกระบวนทัศน์ที่เกิดซ้ำช่วยให้..."
  เหตุผล：ความคล้ายคลึงสูง ความซับซ้อนของคำศัพท์ที่ผิดปกติ รูปแบบจังหวะ

【ประโยค #2】（หน้า 5）ความเสี่ยง：กลาง 🟡 | ความมั่นใจ 72%
  "อัลกอริทึมการเรียนรู้ของเครื่องเริ่มต้นการปฏิวัติ..."
  เหตุผล：ความเบี่ยงเบนทางสถิติ ความหลากหลายของคำศัพท์ต่ำ
```

**📌 วิธีการอ่าน**：
- **หมายเลขหน้า**：ตำแหน่งในเอกสาร
- **สีความเสี่ยง**：แดง（ความเสี่ยงสูง）, เหลือง（ความเสี่ยงกลาง）, น้ำเงิน（ความเสี่ยงต่ำ）
- **เปอร์เซ็นต์ AI**：ความน่าจะเป็นที่เป็น AI（0～100%）
- **เหตุผล**：เหตุใดโมเดลจึงทำเครื่องหมายประโยคนี้

## 6️⃣ ตีความผลลัพธ์（สำหรับครูผู้สอน）

### สถานการณ์ A：ความน่าจะเป็นของ AI โดยรวม > 80%
```
⚠️ หลักฐานที่แข็งแกร่งของการใช้ AI
→ การกระทำ：ตรวจสอบประโยคที่น่าสงสัยอย่างรอบคอบ
→ ต่อไป：คุยกับนักเรียนเกี่ยวกับว่านโยบายอนุญาต AI หรือไม่
```

### สถานการณ์ B：ความน่าจะเป็นของ AI 50～80%
```
🤔 สัญญาณแบบผสม; บางย่อหน้าน่าสงสัย
→ การกระทำ：มุ่งความสนใจไปที่ประโยคที่ทำเครื่องหมายเป็นสีแดง
→ ต่อไป：ตรวจสอบว่าตรงกับสไตล์การเขียนปกติของนักเรียนหรือไม่
```

### สถานการณ์ C：ความน่าจะเป็นของ AI < 30%
```
✅ ดูเหมือนเป็นงานดั้งเดิมของนักเรียน
→ การกระทำ：พิจารณาอนุมัติหรือตรวจสอบประโยคบางประโยค
→ หมายเหตุ：ข้อความของมนุษย์ยังสามารถมีบวกลวงได้
```

## 7️⃣ ดาวน์โหลดและแชร์ผลลัพธ์

### ตัวเลือกการส่งออก
```
1. [📄 ดาวน์โหลด PDF]   → รายงานเต็มรูปแบบพร้อมรายละเอียดทั้งหมด
2. [📊 ส่งออก CSV]      → สำหรับตารางการให้คะแนน
3. [📋 คัดลอกผลลัพธ์]   → สำหรับวางในอีเมล/LMS
```

**PDF รวมถึง**：
- สรุปคำตัดสิน
- เมตริกโดยละเอียด
- ประโยคที่น่าสงสัยทั้งหมดและเหตุผล
- หมายเลขหน้าเพื่อเอกสารอ้างอิงที่ง่าย

## 🆘 ปัญหาทั่วไปและวิธีแก้ไข

### ปัญหา：「การดาวน์โหลดโมเดลล้มเหลว」
```
❌ ข้อผิดพลาด：ไม่สามารถดาวน์โหลดโมเดล RoBERTa
✅ วิธีแก้ไข：
  1. ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต
  2. ปิดใช้งาน VPN/พร็อกซี่
  3. รอ 5 นาทีแล้วลองอีกครั้ง
  4. ล้างแคชเบราว์เซอร์（Ctrl+Shift+Del）
```

### ปัญหา：「การวิเคราะห์ช้ามาก」
```
❌ รอมากกว่า 30 วินาที
✅ วิธีแก้ไข：
  1. การรันครั้งแรกช้า（กำลังโหลดโมเดลลงใน RAM）
  2. การรันครั้งต่อไปใช้เวลา 2～5 วินาที
  3. ปิดแท็บเบราว์เซอร์อื่น
  4. เริ่มต้นเบราว์เซอร์ใหม่หากยังคงช้า
```

### ปัญหา：「เบราว์เซอร์บอกว่า 'หน่วยความจำไม่พอ'」
```
❌ ข้อผิดพลาด：ไม่สามารถจัดสรรหน่วยความจำ
✅ วิธีแก้ไข：
  1. ต้องมี RAM ว่างอย่างน้อย 2 GB
  2. ปิดแอปพลิเคชันอื่น
  3. โหลดหน้าใหม่（Cmd/Ctrl + R）
  4. ลองใช้คอมพิวเตอร์ตั้งโต๊ะ
```

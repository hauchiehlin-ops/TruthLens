# TruthLens — 快速开始指南（简体中文）

**目标**：5 分钟内完成第一份文件分析

---

## 1️⃣ 打开应用程序

### 选项 A：Web 版本（推荐）
```
浏览器：https://truthlens.vercel.app
设备：桌机、平板或手机
```
✅ 无需安装  
✅ 下载模型后可离线使用  
✅ 100% 隐私保护

## 3️⃣ 上传或粘贴文件

### 方式 1：粘贴文本
```
1. 点击「粘贴文本」
2. Ctrl+V（或 Cmd+V）粘贴您的文本
3. 建议至少 100 个字符
```

### 方式 2：上传文件
```
支持的格式：
• .txt（文本文件）
• .docx（Word 文件）
• .pdf（PDF 文件，包含 OCR）
```

### 方式 3：使用相机（移动设备）
```
1. 点击相机图标
2. 拍摄手写作业照片
3. OCR 自动转换图片 → 文本
```

## 4️⃣ 开始分析

## 5️⃣ 查看报告

### 顶部区段：**判定摘要卡**
```
╔════════════════════════════════════╗
║  判定：可能为 AI                    ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━   ║
║  AI 概率：72%                       ║
║  可信度：高度可信 ✓                ║
╚════════════════════════════════════╝
```

**📌 含义**：
- **判定**：整体判断（人类 / 可能人类 / 混合 / 可能 AI / AI）
- **概率**：0-100% 的 AI 生成确信度
- **可信度**：所有检测引擎是否一致

---

### 中间区段：**三列指标卡**
```
┌──────────────┬──────────────┬──────────────┐
│  AI 比例     │ 分析耗时     │  可信度      │
│  ────────    │ ────────     │  ────────   │
│  8/45 (18%)  │  2.3 秒      │  92%        │
└──────────────┴──────────────┴──────────────┘
```

**📌 含义**：
- **AI 比例**：多少句子被标记为 AI（45 句中 8 句）
- **分析耗时**：扫描用时
- **可信度**：整体结果的可靠性

---

### 底部区段：**可疑句子清单**
```
【句子 #1】（第 3 页）风险：高危 🔴 | 信心度 85%
  "整合典范转移能够启用..."
  判定依据：相似度高、词汇复杂度异常、节奏规律

【句子 #2】（第 5 页）风险：中等 🟡 | 信心度 72%
  "机器学习算法已经彻底改变..."
  判定依据：统计特征偏差、词汇多样性低
```

**📌 如何解读**：
- **页数**：文件中的位置
- **风险色彩**：红色（高危）、黄色（中等）、蓝色（低危）
- **AI 百分比**：0-100% 的 AI 可能性
- **判定依据**：为何模型标记该句子

## 6️⃣ 解读结果（教师用）

### 情况 A：整体 AI 概率 > 80%
```
⚠️ 强力 AI 使用迹象
→ 行动：深入检查可疑句子
→ 后续：与学生讨论作业政策是否允许使用 AI
```

### 情况 B：AI 概率 50-80%
```
🤔 混合信号；某些段落可疑
→ 行动：聚焦红色标记句子
→ 后续：检查是否符合该学生的典型写作风格
```

### 情况 C：AI 概率 < 30%
```
✅ 看起来是真正的学生作业
→ 行动：考虑通过，或抽查几个句子
→ 注意：即使人类文本也可能触发假阳性
```

## 🆘 常见问题与解决方案

### 问题：「模型下载失败」
```
❌ 错误：无法下载 RoBERTa 模型
✅ 解决方法：
  1. 检查网络连接
  2. 禁用 VPN/代理
  3. 5 分钟后重试
  4. 清除浏览器缓存（Ctrl+Shift+Del）
```

### 问题：「分析非常慢」
```
❌ 等待 30 秒以上
✅ 解决方法：
  1. 首次运行速度较慢（将模型加载到 RAM）
  2. 后续运行 2-5 秒
  3. 关闭其他浏览器标签页
  4. 如果仍然缓慢，重新启动浏览器
```

### 问题：「浏览器说『内存不足』」
```
❌ 错误：RAM 用尽
✅ 解决方法：
  1. 需要 2GB+ 的可用 RAM
  2. 关闭其他应用程序
  3. 刷新页面（Cmd/Ctrl + R）
  4. 尝试在桌机而非移动设备上使用
```

### 问题：「报告显示『可信度低』」
```
❌ 警告：分析可信度低于 60%
✅ 说明：
  - 某些检测模型无法加载
  - 结果可靠性较低；考虑重新运行
  - 检查「模型安装」面板
```
